SUMCHECK 2 Degree 1 — Theta + Rho + Pi (linear)
Reduces pre-chi claim → input claim  |  Prover sends 1 field element per variable
π
Pi — Lane index permutation
P[φ(x,y)] = ρ[x,y]   where φ(x,y) = (y, (2x+3y) mod 5)
FREE — Just relabeling lane indices, no computation
ρ
Rho — Fixed bit rotation
ρ[x,y] = Rot(θ[x,y], r[x,y])
LINEAR — Cyclic rotation absorbed into sumcheck coefficients via rotation predicate
θ
Theta — Column parity mixing
θ[x,y] = A[x,y] ⊕ ∑s A[x-1,s] ⊕ Rot(∑s A[x+1,s], 1)
LINEAR — All XOR (= addition in F2), rotation is linear
Combined linear map (what the sumcheck actually proves):
Pφ(x,y) = Rot(A[x,y], r[x,y]) ⊕ ∑s Rot(A[x-1,s], r[x,y]) ⊕ ∑s Rot(A[x+1,s], r[x,y]+1)
Each P lane is a sum of ~11 rotated views of input lanes — entirely degree 1 in A
