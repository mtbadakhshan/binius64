2. Theta (θ): Column Parity Mixing

Theta computes the XOR of each column, then mixes neighboring columns. It's the main diffusion step — every lane ends up depending on two other columns.

Step 1: Compute column parities C[x] = XOR of all lanes in column x

Step 2: Compute D[x] = C[x-1] XOR RotateLeft(C[x+1], 1)

D[0] = C[4] XOR RotL(C[1], 1) = 0110 XOR RotL(1011, 1) = 0110 XOR 0111 = 0001
D[1] = C[0] XOR RotL(C[2], 1) = 0110 XOR RotL(0001, 1) = 0110 XOR 0010 = 0100
D[2] = C[1] XOR RotL(C[3], 1) = 1011 XOR RotL(1100, 1) = 1011 XOR 1001 = 0010
D[3] = C[2] XOR RotL(C[4], 1) = 0001 XOR RotL(0110, 1) = 0001 XOR 1100 = 1101
D[4] = C[3] XOR RotL(C[0], 1) = 1100 XOR RotL(0110, 1) = 1100 XOR 1100 = 0000

RotL(x, 1) shifts all bits left by 1, wrapping the top bit to the bottom. Example: RotL(1011, 1) = 0111.

Step 3: Apply correction: A'[x,y] = A[x,y] XOR D[x]

Every lane in column x gets XORed with D[x]:

Pi: Shuffle lane positions

After rotation, each lane moves to a new position: lane at (x,y) moves to (y, (2x+3y) mod 5).
No bits change — just the grid positions shuffle.

(0,0) → (0,0)  (1,0) → (0,2)  (2,0) → (0,4)  (3,0) → (0,1)  (4,0) → (0,3)
(0,1) → (1,3)  (1,1) → (1,0)  (2,1) → (1,2)  ...
Rho + Pi are both linear (degree 0 or 1). Rho just permutes bits within each lane. Pi just permutes lanes within the grid. No computation, no multiplication, zero cost in the sumcheck.

4. Chi (χ): The Only Nonlinear Step

Chi operates on each row independently. For each lane:

out[x] = in[x] XOR ((NOT in[x+1]) AND in[x+2])

χ[0] = 1100 XOR (NOT 0100 AND 1001) = 1100 XOR 1001 = 0101
χ[1] = 0100 XOR (NOT 1001 AND 1110) = 0100 XOR 0110 = 0010 [corrected for illustration]
χ[2] = 1001 XOR (NOT 1110 AND 0001) = 1001 XOR 0001 = 1000
χ[3] = 1110 XOR (NOT 0001 AND 1100) = 1110 XOR 1100 = 0010
χ[4] = 0001 XOR (NOT 1100 AND 0100) = 0001 XOR 0000 = 0001
Chi is the ONLY step with AND (multiplication).
In GF(2): AND = multiplication, XOR = addition, NOT = add 1.
This single AND per lane is what makes chi degree-2 and forces the sumcheck to be degree-2.
Without chi, the entire Keccak round would be linear (degree 1) and trivial to prove.

5. Iota (ι): Add Round Constant

The simplest step: XOR a fixed round constant into lane (0,0). All other lanes unchanged.

Round 0 constant: RC[0] = 0x0000000000000001 (in 64-bit; in 4-bit: 0001)

O[0,0] = χ[0,0] XOR RC[0] = 0101 XOR 0001 = 0100
O[1,0] = χ[1,0] = 0010  (unchanged)
O[2,0] = χ[2,0] = 1000  (unchanged)
... all other lanes unchanged
After one complete round: Every single bit of the 1600-bit state has been modified. The capacity bits (which started as zeros) are now non-zero and depend on the message. After 24 rounds, the relationship between input message and output hash is hopelessly scrambled — that's what makes Keccak a secure hash function.

For the GKR prover: Each round is proved with one degree-2 sumcheck. The chi AND is the only thing that makes it degree 2 (not degree 1). 24 rounds = 24 sequential sumchecks.
